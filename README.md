# Marcos Ferreto Estrada

Undergraduate student in Mathematical Modeling at the University of Costa Rica (UCR), interested in the intersection of applied mathematics, computational science and artificial intelligence.

I learn by building. I like turning mathematical ideas and data problems into working software.

## Selected projects

- **[Lattice](https://github.com/FerretoDev/Lattice)**: a discrete grid-based simulation engine in Python (chunks, constrained fills and rule systems) with tests and a viewer.
- **[E-commerce customer analytics](https://github.com/FerretoDev/mo0005-ecommerce-ml)**: group course project on the Olist dataset. I proposed it, coordinate the team and built the PostgreSQL/Docker database, the KNIME ETL and an order-segmentation model (k-means).
- **[UCR library system](https://github.com/FerretoDev/biblioteca-ucr-grecia)**: AVL tree, red-black tree and hash table implemented from scratch (Data Structures course, in pairs).
- **[Portfolio](https://github.com/FerretoDev/portfolio-dev)**: personal site built with Reflex.

Currently building (private for now): a personal finance web app (FastAPI, React/TypeScript) and a Telegram bot that logs expenses with the Gemini API.
